# 01 — Product

## What is this?

`react-assignment-ui` is a small but production-quality React component library. It
provides a focused set of accessible, typed, and themeable UI primitives that can be
dropped into any React 19 application.

## Goals

- Ship **accessible** components (semantic HTML, ARIA, keyboard navigation, focus
  management) out of the box.
- Provide a **typed** developer experience (TypeScript, JSDoc on every prop).
- Keep **design tokens as CSS variables** so theming is a one-place change.
- Be **framework-light**: no runtime dependency beyond React.

## Non-goals

- This is not a full design system (no date pickers, data grids, or complex charts).
- It does not include a backend or any server-side behavior.
- It does not dictate application architecture; components are unopinionated about
  how consumers manage state, routing, or data fetching.

## Audience

- Frontend engineers building React applications.
- Design-system maintainers looking for a token-driven starting point.
